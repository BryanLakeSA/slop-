# slop~

A browser app for vibe-coding MIDI-controlled instruments. Paste JavaScript instrument code into a codebox, press Run, and play it from a MIDI keyboard. Pasted HTML widgets can see the instrument's audio and control its parameters.

Status: rebooting as a browser app (Chromium-based browsers only). Currently at Step 1, a browser check page at `step1/index.html`.

How to run: open https://bryanlakesa.github.io/slop-/step1/ in a Chromium browser (served from this repo by GitHub Pages).

Browsers: developed and tested in Brave on macOS. Brave needs the folder picker turned on: open brave://flags, enable "File System Access API", and relaunch. Chrome should work without a flag but is untested.

MIT licensed. The earlier Electron prototype was removed; it remains in Git history.
