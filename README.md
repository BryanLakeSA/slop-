slop~

A browser app for MIDI-controlled instruments. Paste JavaScript instrument code into a codebox, press Run, and play it from a MIDI keyboard. Pasted HTML widgets can see the instrument's audio and control its parameters.

Status: rebooting as a browser app (Chromium-based browsers only). Currently at Step 1, a browser check page at step1/index.html.

How to run: open https://bryanlakesa.github.io/slop-/step1/ in Chrome (served from this repo by GitHub Pages).

MIT licensed. The earlier Electron prototype was removed; it remains in Git history.
